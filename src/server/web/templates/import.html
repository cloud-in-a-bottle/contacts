Getting a file to import

  • Google Contacts: contacts.google.com → Export → vCard (for iOS Contacts). Do not pick either CSV format; this importer reads vCards only.
  • iCloud: icloud.com/contacts → select all → the gear menu → Export vCard.
  • Thunderbird: Address Book → Tools → Export, choosing vCard.
